# Introdução
Este é um projeto pessoal onde aprendo a usar banco de dados em h2, e organizar um projeto em Spring Boot.

Este projeto foi feito com base em um estoque de mercado ele possibilita maior coomprensão
dos recursos em seu estabelecimento.

## Funcionalidades

Ele permite registrar locais, produtos e prateleiras.

### Locais
Os locais são o ambiente onde ele age, mercado ou qualquer local, ele permite que tenha vários cadastrados e que cada um tenha
individualmente seus produtos e prateleiras.

### Produtos
São o que há no estoque ou que é utilizado, cada um tem suas propriedades, prateleira em que pertence, quantidade, data de compra e data
de validade e outras coisas.

### Prateleiras
É onde os produtos são posicionados para que clientes possam pega-los, cada produto dentro de sua prateleira tem ela como identificador
do seu "responsável".
